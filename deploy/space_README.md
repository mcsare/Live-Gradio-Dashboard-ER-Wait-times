# ER Pulse

Live Metro Vancouver emergency department wait times, forecasts 1 to 3 hours ahead, and how accurate those forecasts have been.

Wait times are estimates for general information only. In an emergency, call 911.

This Space is deployed automatically from GitHub: https://github.com/mcsare/Live-Gradio-Dashboard-ER-Wait-times
Edit the code there, not here. If the Space has been asleep, the first visit takes 30 to 60 seconds to wake it.
